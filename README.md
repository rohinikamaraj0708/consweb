# BuildPro Construction Website

## Project Description

BuildPro is a responsive construction company website developed using HTML, CSS, and JavaScript.

## Features

- Responsive Navigation
- Hero Section
- Services Page
- Contact Form
- LocalStorage Auto Fill
- SEO Friendly
- Mobile Responsive

## Technologies Used

- HTML5
- CSS3
- JavaScript
